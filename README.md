### Установка

Установка выполняется один раз. При следующих запусках достаточно выполнить одну команду из раздела "Запуск".

1. **Установить Python** - скачайте установщик с [официального сайта](https://www.python.org/downloads/). При установке Windows, если появится опция `Add python.exe to PATH`, включите её.
2. **Установить UV** - следуйте инструкции на [официальном сайте UV](https://docs.astral.sh/uv/getting-started/installation/). Для Windows выберите способ установки через `pip`.
3. **Скачать проект** - [скачайте архив с исходным кодом](https://github.com/qvp/vk_search/archive/refs/heads/main.zip).
4. **Распаковать архив** в удобную папку, чтобы случайно не удалить и не потерять историю просмотров.
5. **Открыть папку проекта в терминале.** Для этого откройте папку проекта в Проводнике Windows, скопируйте путь включая саму папку и выполните в командной строке (терминале) команду `cd {ПУТЬ_К_ПАПКЕ}`.

Если кажется сложно - скопируйте эту инструкцию в нейросеть и попросите объяснить.

### Запуск
1. Откройте папку проекта в терминале, если она ещё не открыта.
2. Выполните команду:
   ```powershell
   uv run uvicorn app.main:app --reload
   ```
3. Открыть в браузере http://localhost:8000

### VK Access token
Для поиска людей используется официальное ВКонтакте API для запросов к нему нужно авторизоваться с любого аккаунта ВКонтакте (не обязательно с основного).

Если вы не хотите авторизовываться или что-то ставить на свой ПК, можете воспользоваться "облегченной" альтернативой, она работает в браузере без установки и авторизации (но имеет гораздо меньший функционал) https://vk.alex.md

### Хранение данных
История просмотров хранится в файле database.sqlite в папке проекта (создается автоматически при первом запуске).

Чтобы перейти на новую версию программы, нужно скопировать этот файл в папку с новой версией.

Можно экспортировать данные в Excel (на странице настроек).
